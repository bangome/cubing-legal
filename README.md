# Cubing — 법무·지원 문서

앱 스토어가 요구하는 **공개 URL**을 제공하기 위한 정적 페이지 저장소다.
Cubing 앱 본 저장소는 비공개이며, 비공개 저장소는 GitHub Pages를 쓸 수 없어 문서만 분리했다.

| 문서 | URL |
|---|---|
| 고객 지원 | https://bangome.github.io/cubing-legal/support.html |
| 개인정보처리방침 | https://bangome.github.io/cubing-legal/privacy.html |
| 이용약관 | https://bangome.github.io/cubing-legal/terms.html |

## ⚠️ 이 파일들은 사본이다

원본은 앱 저장소의 `public/` 아래에 있다. **양쪽을 함께 고쳐야 한다** — 앱 안에서
설정 화면이 참조하는 것은 원본이고, 스토어가 참조하는 것은 이쪽이다.

사본을 만들 때 절대경로 링크(`/privacy.html`)를 상대경로로 바꿨다. 프로젝트 Pages는
`/cubing-legal/` 하위에 놓여 절대경로가 도메인 루트로 향해 깨지기 때문이다.
